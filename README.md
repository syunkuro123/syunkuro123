## 公開プロジェクト

### [病院向けAIリスキリング](https://github.com/syunkuro123/sun-ai-reskilling-lp)

S.U.Nの病院向けAI研修を紹介するWebサイト。AIの基礎理解から実務演習、定着支援まで、現場で使い始めるための支援内容をまとめています。

### [AI導入診断](https://github.com/syunkuro123/ai-reskilling-diagnosis)

AI導入の現在地と次の一手を確認するWebツール。経営者・管理職・現場担当者・一般職員向けに、業界を問わず利用できる構成です。

[公開サイトを見る](https://ai-reskilling-diagnosis.vercel.app/)
